# 02. Stakeholder Map and RACI

**Note:** Assumed stakeholders for a simulated project. No interviews were held.

## 1. Stakeholder map

| Stakeholder | Role in this project | Interest | Influence | Needs | Engagement |
|---|---|---|---|---|---|
| CEO / Executive sponsor | Sponsor, receives the Monday summary | High | High | Size of the problem, one-page view | Keep satisfied: Page 1 only, short briefing |
| Retention Manager | Primary user and decision maker on actions | High | High | Segment priorities, triggers, test results | Manage closely: weekly review |
| Retention Agents | Make the calls | High | Medium | A ranked, clear call list | Keep informed: Page 3 training |
| Customer Support Lead | Owns ticket handling | Medium | Medium | Ticket threshold for escalation | Consult before changing ticket process |
| CRM / Marketing Lead | Owns emails and contract offers | Medium | Medium | Inactivity point, contract offer targets | Consult for the day-30 and contract actions |
| Finance Analyst | Checks revenue figures | Medium | Medium | Metric definitions | Keep informed: metric dictionary |
| Data / BI team | Maintain data and dashboard | Medium | Medium | Clear requirements, definitions | Collaborate throughout |

## 2. Power / interest grid

| | Low interest | High interest |
|---|---|---|
| **High influence** | | CEO, Retention Manager (manage closely) |
| **Medium influence** | | Retention Agents (keep informed) |
| **Medium influence** | Finance Analyst (keep informed) | Support Lead, CRM Lead, BI team (consult) |

## 3. RACI

R = Responsible, A = Accountable, C = Consulted, I = Informed

| Activity | CEO | Retention Manager | Retention Agents | Support Lead | CRM Lead | Finance | BI team |
|---|---|---|---|---|---|---|---|
| Approve the High Risk definition | I | A | I | C | C | C | R |
| Maintain data and dashboard | I | C | I | I | I | I | A/R |
| Publish weekly call list | I | A | I | I | I | I | R |
| Contact high-risk customers | I | A | R | C | C | I | I |
| Design and run the holdout test | I | A | R | C | C | C | R |
| Set the success threshold before the test | C | A | I | C | C | R | C |
| Report test results | I | A/R | I | I | I | C | C |
| Decide whether to scale | A | R | I | C | C | C | I |
| Validate revenue figures | I | C | I | I | I | A/R | C |

## 4. Communication plan

| Audience | What | When | Format |
|---|---|---|---|
| CEO | Executive Summary page | Weekly | Dashboard page, 1 minute |
| Retention Manager | Drivers page, test status | Weekly | Dashboard plus 15-minute review |
| Agents | Call list | Weekly | Page 3 |
| Finance | Metric changes | When definitions change | Metric dictionary |
